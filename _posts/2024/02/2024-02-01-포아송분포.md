## 개요
### 포아송 분포란?

포아송 분포(Poisson distribution)는 **단위 시간(혹은 공간) 동안 어떤 사건이 몇 번 일어나는지**를 나타내는 분포다. 예를 들어 1시간 동안 콜센터에 걸려오는 전화 수, 하루 동안 매장에 방문하는 손님 수처럼 "드물게, 그러나 꾸준히" 발생하는 사건의 횟수를 모델링할 때 쓴다.

![포아송 분포](/assets/images/posts/poisson/poisson-dist.png)

## 본론
### 가정
1. 하나의 사건은 다른 사건에 영향을 끼치지 않는다. 서로 다른 사건은 독립적이여야 한다.
2. 사건은 단위 구간 동안 일정한 평균 비율 $\lambda$로 발생한다.
3. 아주 짧은 순간에 두 사건이 동시에 일어나지는 않는다.

이 가정 아래에서, 단위 구간 동안 사건이 $x$번 일어날 확률은 다음과 같다.

$$ f(x) = \frac{e^{-\lambda} \lambda^x}{x!}, \quad x = 0, 1, 2, \dots $$

여기서 $\lambda$는 단위 구간당 평균 발생 횟수다. 포아송 분포의 **평균과 분산이 모두 $\lambda$로 같다**는 점이 가장 큰 특징이다.

## 파이썬으로 그리기
### 1. 직접 그리기
```python
import numpy as np
import matplotlib.pyplot as plt
from math import factorial, exp

def pois(x, lam) :
    return exp(-lam)*lam**x/factorial(x)

x = np.arange(60)
p = np.array([pois(i,10) for i in range(60)])

plt.bar(x, p, color = 'royalblue')
```

### 2. scipy.stats를 활용하기
직접 구현하지 않고 `scipy.stats.poisson`으로 더 간단히 그릴 수도 있다.

```python
from scipy.stats import poisson

x = np.arange(60)
plt.bar(x, poisson.pmf(x, mu=10), color='royalblue')
```

`pmf`는 확률질량함수, `cdf`는 누적분포함수를 준다. 인자 `mu`가 곧 $\lambda$에 해당한다.
